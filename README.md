# Blockera

A browser extension that blocks distracting sites with a dismissible blur overlay.

Add sites to your block list, and when you visit them you'll get a "Stay Focused"
screen. Dismiss it for a one-time pass, or pick a timeout (5 / 15 / 30 / 60 min)
to temporarily allow access with a countdown timer.

Built with [WXT](https://wxt.dev) + React + TypeScript.
